Initial experimental release of ESPHome Water Heater Status for the Freenove ESP32-WROVER-E camera board and the Honeywell/Resideo WT8840 LED pattern.

The ESP32 reads the external green status LED locally and exposes one primary Home Assistant sensor: **Running**, **Not running**, **Fault**, or **Unknown**. It publishes state changes, with camera and calibration entities disabled by default.

Includes the ESPHome configuration, two C++ headers, installation and calibration guides, compatibility notes, host timing tests, CI firmware checks, and an MIT license for use and modification. The source ZIP and SHA256SUMS accompany GitHub's source archives. Build with ESPHome 2026.8.2 and your own secrets; no preconfigured firmware is distributed.

**First install:** classification starts off. Follow the calibration guide to enable it, verify the normal patterns and return HA to one enabled entity.

**Validation limits:** the initial installation has physical burner-off confirmation and captured normal strobe timing, but its exact control model and independent burner-on check remain unverified. Fault patterns are tested in software; no physical heater fault was induced. This is an observer of the control's indicator, not independent flame proof. Other blink schemes and camera boards need their own validation.
