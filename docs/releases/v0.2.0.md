Adds passive transition capture to the experimental water-heater LED monitor.

The ESP32 saves up to 64 bounded RAM windows around every status change, including successful transitions. Each window contains up to 15 seconds of preceding evidence and 20 seconds afterward: LED edges, pulse widths, normal/fault group observations, image health and the reason for Unknown.

A read-only encrypted API action exports completed traces in small pages. The included collector saves them locally and summarizes complete heating cycles and Unknown occurrences. Home Assistant still has one primary status sensor with change-only reporting; no continuous image or diagnostic stream is added.

**Upgrade:** copy all four headers and the YAML together. Retain your existing node and entity names and your own secrets. Follow the transition-capture guide for collector setup. The classifier is unchanged. Captures live in PSRAM, are finite and are lost on reboot unless collected. The original hardware/control compatibility and physical-validation limits continue to apply.

Includes tests for window retention, overflow, timer wraparound and cycle analysis. Build with ESPHome 2026.8.2. This remains an experimental, source-only release under the MIT license.
